======================

1. The improved CNN achieved 63.83% test accuracy.

2. Compared with the previous CNN baseline:
   Previous CNN Test Accuracy: 52.47%
   Improved CNN Test Accuracy: 63.83%
   Absolute improvement: +11.36 percentage points.

3. Compared with the tuned HOG + Linear SVM:
   Tuned HOG Test Accuracy: 45.14%
   Improved CNN Test Accuracy: 63.83%
   Absolute difference: +18.69 percentage points.

4. The model was trained on CPU only using an Intel Core i3
   10th Generation processor.

5. The model contains 305,639 total parameters, which is substantially
   smaller than many large modern CNN architectures.

6. Data augmentation was applied only to the training data.
   Validation and test data were not augmented.

7. ReduceLROnPlateau reduced the learning rate during training when
   validation loss stopped improving sufficiently.

8. EarlyStopping was enabled, but training reached the maximum of
   30 epochs because the stopping condition was not reached for the
   required patience period.

9. The best validation accuracy was 63.95% at epoch 28.

10. The Disgust class remains difficult:
    Precision: 0.8182
    Recall: 0.1636
    F1: 0.2727
    Test support: 55 samples.

11. The relatively low Disgust recall is related to the strong class
    imbalance in FER2013 and should be discussed as a limitation.

12. Macro F1 is lower than accuracy because macro F1 gives equal
    importance to each class, while accuracy is affected strongly by
    the number of samples in each class.

13. No class weights were used in this experiment.

14. No transfer learning was used.

15. No external dataset was used.

16. The test set was used only for final evaluation after training.

NOTES FOR REPORT
================
The purpose of the improved CNN experiment was to evaluate whether
a deeper convolutional architecture with normalization, regularization,
data augmentation and adaptive learning-rate scheduling could learn
more discriminative image representations than the simpler CNN baseline.

The CNN learns image features automatically through convolutional
filters instead of using a manually designed feature descriptor such
as HOG.

The deeper architecture uses multiple convolutional blocks with
increasing numbers of filters (32, 64 and 128), allowing the network
to learn increasingly complex visual representations.

Batch Normalization was included to stabilize the training process.

Dropout was used as a regularization technique.

Global Average Pooling was used before the dense classification layer,
reducing the need for a large fully connected layer.

Data augmentation was applied to the training images to expose the
model to small variations in the input images.

ReduceLROnPlateau was used to reduce the learning rate when validation
loss stopped improving.

EarlyStopping was used to prevent unnecessary training if validation
loss stopped improving for several consecutive epochs.
